# python-management

## 🎓 Student Registration System

A simple student registration and login system developed using Python.

### 🛠️ Technologies Used

* Python
* Tkinter (GUI)
* SQLite3 (Database)

### ✨ Features

* Register new users
* Store user information in a database
* Display registered users
* Search users by password
* User login system
* Welcome window after successful login
* Delete user records with confirmation
* Clear input fields

### 📸 Project Description

This project provides a graphical interface for registering students and managing their information.

Users can enter their first name, last name, course name, and password. Their information is stored in an SQLite database.

Registered users can log in using their password.

### 🚀 How to Run

1. Install Python.
2. Download or clone this repository.
3. Run the main Python file:

python main.py
